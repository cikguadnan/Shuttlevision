# ShuttleVision 🏸

Mobile-first badminton vision and training app.

## V1
- Live phone camera
- Rear/front camera switching
- Rally start/end workflow
- Manual shot counter for validating the UX before automatic detection
- Rally duration tracking
- Session statistics
- Local session history

## Roadmap
- V1.1: automatic player/court detection
- V1.2: experimental shuttle/contact detection
- V2: pose + footwork tracking and court heatmaps
- V3: shot classification
- V4: highlights and coaching reports

## Run
This is a static web app. Enable GitHub Pages for the repository (Deploy from branch: `main`, `/root`) or serve the files locally over HTTPS. Camera access requires HTTPS on phones.

The first goal is to validate camera positioning and rally UX on a real badminton court before adding heavier ML models.
